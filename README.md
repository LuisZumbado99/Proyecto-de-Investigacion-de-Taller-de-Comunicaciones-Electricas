# Proyecto Integral de Investigación y Diseño - Taller de Comunicaciones Eléctricas

Este repositorio contiene la Prueba de Concepto (PoC) y el desarrollo completo de un proyecto de ingeniería enfocado en las áreas de **Integridad de Señal (SI)**, **Integridad de Potencia (PI)** o **Compatibilidad/Interferencias Electromagnéticas (EMC/EMI)**.

## Metodología
Desarrollado bajo el marco de trabajo **CDIO** (*Concebir, Diseñar, Implementar, Operar*) y la metodología de **Aprendizaje Basado en Problemas (PBL)**.

## Toolchain de Código Abierto
El proyecto utiliza un entorno de herramientas multiplataforma (disponible en Linux, Windows y macOS):

* **Diseño esquemático y PCB:** KiCad
* **Simulación electromagnética (Full-Wave 3D):** openEMS
* **Simulación circuital:** NGspice / Qucs-s
* **Procesamiento y análisis:** Python (`scikit-rf`)
